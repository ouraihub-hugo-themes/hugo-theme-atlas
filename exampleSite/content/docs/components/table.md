普通 Markdown 表格。渲染 hook 只做一件 Markdown 语法做不到的事：套一层滚动
包裹，让宽表自己滚而不撑开版面。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | string | — | 页面标题。不写就用文件名。 |
| `weight` | int | `0` | 排序权重。升序。 |
| `draft` | bool | `false` | 草稿不进生产构建。 |

## 对齐

Markdown 的 `:---:` 转成 `data-td-align`，不是行内 `style` —— 属性策略里
`style` 是"不安全直接丢"，模板自己再吐一个就自相矛盾了，而且 CSP 会拦。

| 左 | 居中 | 右 |
| :--- | :---: | ---: |
| a | b | c |
| 长一些的内容 | 中 | 42 |

## caption

`caption` 属性渲染成原生 `<caption>`，不是外面套个段落 —— 它与表格的关联
要能被辅助技术读出来。

## 宽表

超出正文列宽时横向滚动。溢出时 `scroll-region.ts` 会给包裹层加
`tabindex="0"`，键盘才能滚它；没溢出的表不加 —— 那会是一个停下来什么都做不了
的 tab 站点。

| 字段 | 类型 | 可空 | 默认值 | 索引 | 约束 | 迁移引入 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `id` | bigint | 否 | 自增 | 主键 | `PRIMARY KEY` | `0001_init` | 行标识，不复用 |
| `created_at` | timestamptz | 否 | `now()` | btree | `NOT NULL` | `0001_init` | 创建时刻，带时区 |
| `updated_at` | timestamptz | 是 | — | — | — | `0004_touch` | 最后一次修改，触发器维护 |
| `payload` | jsonb | 是 | `'{}'::jsonb` | gin | `CHECK (jsonb_typeof(payload) = 'object')` | `0007_payload` | 结构化载荷，按键查询 |
| `status` | text | 否 | `'pending'` | btree | `CHECK (status IN ('pending','active','done'))` | `0009_status` | 状态机当前值 |

## matrix

`.matrix` 粘连表头与首列。首列渲染成 `th[scope="row"]` —— 粘连需要它，而
那也是正确语义：那一列在标识行，不在陈述数据。

这张表两个方向都超出，滚动时表头留在顶上、首列留在左边，左上角那格压在两者
之上 —— 它同时属于两个方向。

## full-width

`.full-width` 让表格借用正文两侧的余量。只在宽屏生效 —— 窄屏没有余量可借。

| 命令 | 作用 |
| --- | --- |
| `pnpm dev` | CSS、TS、Hugo 三个 watch 一起跑 |
| `pnpm check` | 类型检查 + lint + 单测 |
| `pnpm icons:build` | 按 `data/icons.json` 重建 sprite |
{.full-width}
