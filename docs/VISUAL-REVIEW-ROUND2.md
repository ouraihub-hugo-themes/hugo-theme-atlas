解析」是对的，根因就是它**，不是引入方式也不是 `display:none`。

实测三种形式（同一个 `<use>`，只换 `href`）：

| 形式 | `getBBox().width` |
| --- | --- |
| `#book`（同文档） | 13.125 |
| `/dist/icons.svg#book` | 0 |
| `http://localhost:1320/dist/icons.svg#book` | 0 |

改成：名字在渲染时登记进 Page Store，`content/icon-sprite.html` 在正文之后把**本页
用到的** symbol 内联到文档末尾（landing 42 次调用落在 12 个图标上，6.1 KB 而不是
整份 25.6 KB）。id 加 `td-i-` 前缀，避免与作者标题锚点撞 id。

### 1. capabilities 的 partial 档图标 —— ✅ 已定，换成减号（2026-09-03）

用户看四种方案的对照图后拍板：**partial 档用 `minus`（减号）**。已改
`capabilities.html` 与 `data/icons.json`（72 个 symbol）。

原来是 `angle-down`（向下箭头）。换掉的理由是它不是「没有对应字形」而是
**有对应字形却在额外表意**：向下箭头读成「展开」或「下载」，锤子读成「在建设
中」，警示三角比实际情况严重。减号在形状上处于勾与叉之间，语义上是空的 ——
这一档要的正是这个。

后 72 个。那一条是没查清单就下的结论。

截图约定）：A `angle-down`、B partial 不出图标、C 三档都不出图标、D `minus`。
