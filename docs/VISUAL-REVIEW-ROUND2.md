## 图标缺陷的修法与现状

跨文档 `<use href="/dist/icons.svg#id">` 在 Chrome 与 Safari 里不解析 —— 那种写法
只有 Firefox 实现过，SVG 2 已把外部引用从规范里去掉。**你定位到「跨文件 use 不
解析」是对的，根因就是它**，不是引入方式也不是 `display:none`。

实测三种形式（同一个 `<use>`，只换 `href`）：

| 形式 | `getBBox().width` |
| --- | --- |
| `#book`（同文档） | 13.125 |
| `/dist/icons.svg#book` | 0 |
| `http://localhost:1320/dist/icons.svg#book` | 0 |

改成：名字在渲染时登记进 Page Store，`content/icon-sprite.html` 在正文之后把**本页
用到的** symbol 内联到文档末尾（landing 42 次调用落在 12 个图标上，6.1 KB 而不是
整份 25.6 KB）。id 加 `td-i-` 前缀，避免与作者标题锚点撞 id。

已量到的当前状态（1280 宽，等 500ms 后读）：

- landing 全页 42 个 `<use>`，**零宽 0 个**，宽度区间 11.47–17.97
- `#capabilities-17` 三档图标各就位：`check` 14.0、`angle-down` 12.0、`close` 12.0
- 静态门禁已进 `check-outputs.js`：引用与定义配平，且禁掉 `*.svg#` 这个形状

**两处纠正你的报告**（不影响结论，但重测时别再按旧前提看）：
