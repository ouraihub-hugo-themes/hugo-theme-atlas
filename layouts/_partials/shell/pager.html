{{- /* 顺序阅读翻页。用 .PrevInSection / .NextInSection 而非 .Prev / .Next： 后者跨 section 走整站顺序，读者读完一节会被丢到无关的另一节。 方向要调换。Hugo 的 Next/Prev 按集合顺序定义，而默认集合是 weight 升序 —— 于是 .NextInSection 指向 weight 更小的页面，也就是阅读顺序 里的上一篇。命名与阅读方向相反，这里换回来。 */ -}} {{- $prev := .NextInSection -}} {{- $next := .PrevInSection -}} {{- if or $prev $next -}} {{- /* 同面包屑：翻页链接带的是**邻页**的标题，进了本页索引就是搜到 A 却 因为 B 的标题命中。 */ -}}
